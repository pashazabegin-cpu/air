# ТЗ и решения: лендинг AIRSCAPE — AERON 2/0

Макет: https://www.figma.com/design/2QeEKXgDdmQ67VcUvsMpkm/Quadcode_test_Zabegin-Pasha
(основной фрейм 51:5, блок со стеклом 1:165). Вёрстка только под десктоп, артборд 1440 px.

## Запуск
```
npm install
npm run dev      # http://127.0.0.1:8765  (?glass — панель настройки стекла)
npm run build    # сборка в dist/
npm run frames   # пересобрать кадры поворота из public/video/hero.mp4
npm run images   # пересжать PNG из design-ref/assets в WebP
```

## Стек (решено)
- Vite + TypeScript, без фреймворка: все эффекты работают с реальным DOM, скроллом и WebGL.
- Lenis — плавный скролл; GSAP ScrollTrigger — все анимации от скролла; GSAP SplitText — текст.
  Всё идёт от одного тикера GSAP, поэтому видео, текст, параллакс и стекло синхронны.
- liquidGL v2.2.4 (MIT, vendor/liquidGL) — жидкое стекло, режим WebGL2
  (в WebGPU плашки «застревали», когда уходили за край экрана).
- Не используем: DawnTransition (это iOS/Swift), lax.js (второй цикл скролла, конфликт с Lenis),
  front-end-daily-challenges (лицензия CC BY-NC, только как идеи).
- Размеры: `--u = 100vw / 1440`, все значения из Figma умножаются на него.
- Шрифты (бесплатные, OFL, раздаются с сайта через @fontsource):
  заголовки, цены и €300 — Geist ExtraLight 200; весь остальной текст — IBM Plex Mono Light 300;
  логотип — IBM Plex Mono Medium; цифры — Doto. Моно шире Aeonik, поэтому текст на стеклянных
  плашках 28/38 вместо 34/43 (чтобы остаться в две строки), текст About шириной 333 (как в пробе в Figma).
- Aeonik и Monoglyphic лежат только в design-ref/fonts (для превью, исключены из git и из сборки).

## Hero-видео (hero.mp4, 2560×1440, 24 fps)
- 0 → 6,0 с — прелоадер: видео играет, интерфейс собирается (логотип крутится как лоадер,
  меню, лейблы, заголовок+текст синхронно, кнопка). Скролл заблокирован.
- На 6,0 с видео останавливается (последний кадр перед поворотом) — совпадает с hero в макете.
- Дальше 68 кадров (6,0 → 8,83 с) идут покадровой секвенцией на canvas: hero закреплён на один
  экран скролла, за который девушка поворачивается в камеру и застывает.
- Потом страница без шторки уезжает в About: низ hero и верх About одного цвета, стык бесшовный.
- Видео подогнано к макету: left −28, top 38, ширина 1484 (в пикселях артборда).

## Блок About (media/about-scroll.mp4, 2304×1440, 107 кадров)
- Видео — это вся сцена: фон, надпись AERON 2/0 и вращающаяся маска. Справа HTML-текст.
- При въезде проявляются заголовок и текст. Затем блок закрепляется: плашки проезжают по центру
  1:1 со скроллом, а видео растянуто ровно на этот проход (первая плашка — старт, последняя — конец).
- Стекло преломляет живое видео: canvas с кадрами подключён к liquidGL как видео
  (refractLive в src/lib/glass.ts, опирается на внутренности liquidGL 2.2.4).
- Низ последнего кадра совпадает по цвету с началом следующего блока.

## Текст
- Заголовки (45/50 px) и цены: по словам, blur → чётко + подъём (как TextReveal "fade-in-blur").
- Остальной текст: «призрачный» текст проявляется по словам (как Magic UI TextRevealByWord).
- Внутри одной группы `[data-reveal-group]` всё стартует и заканчивается одновременно.

## Параллакс и прочие эффекты
- `data-parallax="N"` — сдвиг на N px артборда за проход через экран (шарики, продукты,
  карта, женщина в финале).
- Дрон влетает при скролле, цифры 600 km / 12 kg считают, CO₂ считает вниз до 0.
- Карточки форматов поднимаются со сдвигом, надпись AERON 2/0 в футере дрейфует.

## Зерно и футер
- Зерно из Figma — белый шум, осветляющий фоны в среднем на ~11% (замерено по экспорту макета).
  Тайл public/img/grain.png (npm run grain) лежит на градиентных фонах, но не на видео.
  В финальном блоке он над затемнением, как в макете, поэтому футер того же тона.
- Большая надпись AERON 2/0 в футере — картинка из Figma (public/img/aeron-footer.webp):
  у слоя прогрессивное размытие, которое CSS не повторяет. Лежит под затемнением, как в макете.
