# ТЗ и решения: лендинг AIRSCAPE — AERON 2/0

Макет: https://www.figma.com/design/2QeEKXgDdmQ67VcUvsMpkm/Quadcode_test_Zabegin-Pasha
(основной фрейм 51:5, блок со стеклом 1:165). Макет только десктопный (артборд 1440 px);
планшет и телефон собраны по нему без отдельного макета — см. «Адаптив».

## Запуск
```
npm install
npm run dev      # http://127.0.0.1:8765  (?glass — панель настройки стекла)
npm run build    # сборка в dist/
npm run frames   # пересобрать кадры поворота из public/video/hero.mp4 (и лёгкие копии *-lite)
npm run images   # пересжать PNG из design-ref/assets в WebP
```

## Стек (решено)
- Vite + TypeScript, без фреймворка: все эффекты работают с реальным DOM, скроллом и WebGL.
- Lenis — плавный скролл; GSAP ScrollTrigger — все анимации от скролла; GSAP SplitText — текст.
  Всё идёт от одного тикера GSAP, поэтому видео, текст, параллакс и стекло синхронны.
- liquidGL v2.2.4 (MIT, vendor/liquidGL) — жидкое стекло, режим WebGL2
  (в WebGPU плашки «застревали», когда уходили за край экрана).
- Не используем: DawnTransition (это iOS/Swift), lax.js (второй цикл скролла, конфликт с Lenis),
  front-end-daily-challenges (лицензия CC BY-NC, только как идеи).
- Размеры: `--u = 100vw / 1440`, все значения из Figma умножаются на него.
- Шрифты (бесплатные, OFL, раздаются с сайта через @fontsource):
  заголовки, цены и €300 — Geist ExtraLight 200; весь остальной текст — IBM Plex Mono Light 300;
  логотип — IBM Plex Mono Medium; цифры — Doto. Моно шире Aeonik, поэтому текст на стеклянных
  плашках 28/38 вместо 34/43 (чтобы остаться в две строки), текст About шириной 333 (как в пробе в Figma).
- Aeonik и Monoglyphic лежат только в design-ref/fonts (для превью, исключены из git и из сборки).

## Hero-видео (hero.mp4, 2560×1440, 24 fps)
- Прелоадер (фрейм 64:505): знак крутится над «дышащим» свечением, счётчик 01 → 100 идёт по
  реальной загрузке (шрифты, снимок стекла, кадры hero, видео до 6,0 с), но не быстрее ~1,4 с.
  Потом знак гаснет, свечение расходится, белый фон растворяется в hero.
- 0 → 6,0 с — интро: видео играет, шапка целиком выезжает сверху, затем лейблы,
  заголовок+текст синхронно и кнопка. Скролл заблокирован.
- На 6,0 с видео останавливается (последний кадр перед поворотом) — совпадает с hero в макете.
- Дальше 68 кадров (6,0 → 8,83 с) идут покадровой секвенцией на canvas: hero закреплён на один
  экран скролла, за который девушка поворачивается в камеру и застывает.
- Потом страница без шторки уезжает в About: низ hero и верх About одного цвета, стык бесшовный.
- Видео подогнано к макету: left −28, top 38, ширина 1484 (в пикселях артборда).

## Блок About (media/about-scroll.mp4, 2304×1440, 107 кадров)
- Видео — это вся сцена: фон, надпись AERON 2/0 и вращающаяся маска. Справа HTML-текст.
- При въезде проявляются заголовок и текст. Затем блок закрепляется: плашки проезжают по центру
  1:1 со скроллом, а видео растянуто ровно на этот проход (первая плашка — старт, последняя — конец).
- Стекло преломляет живое видео: canvas с кадрами подключён к liquidGL как видео
  (refractLive в src/lib/glass.ts, опирается на внутренности liquidGL 2.2.4).
- Низ последнего кадра совпадает по цвету с началом следующего блока.

## Текст
- Заголовки (45/50 px) и цены: по словам, blur → чётко + подъём (как TextReveal "fade-in-blur").
- Остальной текст: «призрачный» текст проявляется по словам (как Magic UI TextRevealByWord).
- Внутри одной группы `[data-reveal-group]` всё стартует и заканчивается одновременно.
- Ссылки меню и кнопка Pre-order now (`data-roll`): при наведении буквы по очереди уезжают вверх,
  снизу выкатывается копия (как TextStaggerHover с 21st.dev: 0,3 с, шаг 25 мс). Только CSS + разбивка
  на буквы в src/lib/text-roll.ts; React/motion не нужны. Другим кнопкам — просто добавить `data-roll`.
- Ховер меню (фреймы 65:614 и 65:556): тёплое свечение #FCECCD поднимается от нижнего края шапки
  под ссылкой; в полной шапке оно поверх текста, в компактной — под ним, как в макете.
  Металлические кнопки при наведении растут до 1.05 (через CSS `scale`, отдельно от transform GSAP).
- Курсор (фрейм 70:796, src/lib/cursor.ts), только для мыши: точка 6 px и стеклянный круг
  28 px (как в референсе cursor-follower), над ссылками/кнопками/полями — 40 px из Figma. Точка
  догоняет указатель с плавностью 0.2, круг — 0.1. Точка белая в режиме difference: тёмная на
  светлом, белая на тёмном. Стекло — преломление карточек About (liquidGL: refraction 0.012,
  bevel 0.09/0.2, aberration 0.15, два блика), но живое и без матовости: центр прозрачный, гнётся и
  расходится по цветам только край. Сам liquidGL преломляет лишь снимок About, поэтому в Chromium
  это SVG-фильтр в backdrop-filter; в Safari/Firefox — просто лёгкий тон.
  На родителях круга нельзя opacity/filter/mix-blend-mode — стекло перестанет видеть страницу.
- Прогрессивный блюр у нижнего края экрана (src/lib/edge-blur.ts, как ProgressiveBlur из референса):
  полоса 130 px, 8 слоёв backdrop-blur 0…7 px, каждый через свою полосу маски. Уезжает вниз, когда
  появляется нижняя строка подвала (©2056), чтобы она оставалась чёткой. Сила — BLUR_STEP, высота — CSS.

## Параллакс и прочие эффекты
- `data-parallax="N"` — сдвиг на N px артборда за проход через экран (шарики, продукты,
  карта, женщина в финале).
- Дрон влетает при скролле, цифры 600 km / 12 kg считают, CO₂ считает вниз до 0.
- Карточки форматов поднимаются со сдвигом, надпись AERON 2/0 в футере дрейфует.

## Зерно и футер
- Зерно из Figma — белый шум, осветляющий фоны в среднем на ~11% (замерено по экспорту макета).
  Тайл public/img/grain.png (npm run grain) лежит на градиентных фонах, но не на видео.
  В финальном блоке он над затемнением, как в макете, поэтому футер того же тона.
- Большая надпись AERON 2/0 в футере — картинка из Figma (public/img/aeron-footer.webp):
  у слоя прогрессивное размытие, которое CSS не повторяет. Лежит под затемнением, как в макете.

## Адаптив (src/styles/responsive.css, src/lib/layout.ts)
- Три раскладки: десктоп от 1200 px — макет как есть (`--u = 100vw / 1440`); ниже поток колонками:
  планшет 600–1199 и телефон до 600. Брейкпоинты продублированы в layout.ts, держать в синхроне.
- Ниже 1200 `--u` становится `--m` — компактной единицей около 1 px (телефон: 100vw/390, от 0.86
  до 1.2; планшет: 100vw/768, от 1 до 1.2). Поэтому всё нарисованное в Figma (лого, кнопки,
  карточки, тумблеры, орбы) живёт в своём масштабе без переписывания, а в responsive.css только
  раскладка страницы. Карточки About и форматов масштабируются локальным `--u` под колонку.
- Скрипты берут размер дизайн-пикселя из живого `--u` (unit() в layout.ts), а не считают сами.
- Hero и About — закреплённые сцены, они учитывают ориентацию: в портрете текст над картинкой
  (видео чуть выше половины экрана, по центру на девушке; маска About внизу экрана), в альбомной —
  композиция десктопа; для низких экранов (телефон боком) — своя уменьшенная версия.
  Позиции от низа экрана считаются от 100svh (видимая часть), сама сцена 100vh — панели браузера
  на iOS не перекрывают кнопку и не оставляют щель снизу.
- Шапка: лого, иконки и бургер; ссылки превращаются в выпадающую панель (src/lib/menu.ts), скролл
  на время меню заблокирован, ссылка закрывает панель и плавно ведёт к разделу.
- Places, Flown, конфигуратор, финал и футер перестраиваются сеткой; форматы — горизонтальная
  карусель со snap. Сегментные переключатели — CSS-дорожка, «таблетка» берёт размер выбранной опции.
  На телефоне в финале сначала текст и форма (на светлой части фона), потом фото, потом футер.
- Лёгкий режим для тач-устройств (`html.is-lite`, `(hover: none) and (pointer: coarse)`):
  - кадры hero/About из public/frames/*-lite (1600 px, 1 + 2 МБ) рисуются из <img>, которые браузер
    декодирует по мере надобности (соседние кадры — заранее через decode()); на десктопе все кадры
    декодированы заранее (около 2,4 ГБ — телефону не по силам);
  - стеклянные карточки About — CSS backdrop-filter вместо liquidGL (тот снимает и преломляет
    всю сцену на GPU); прогрессивный блюр у нижнего края выключен; курсор и так только для мыши;
  - iOS качает видео, только когда оно играет: под прелоадером оно запускается без звука и встаёт
    на первом кадре, прелоадер ждёт 2 с видео; без автоплея (режим энергосбережения) вместо видео
    сразу стоит первый кадр поворота.
- iOS-мелочи: без увеличения шрифта при повороте, поле e-mail не меньше 16 px (иначе Safari
  зумит), без серой подсветки при тапе, увеличенная зона нажатия у «+» на карточках.
- Проверено в браузере на 360×640, 390×844, 768×1024, 1024×768, 844×390 и 1440×900 (десктоп
  без изменений). На реальном iPhone / в iOS-симуляторе не проверялось — на машине нет Xcode.
